How to read this document

Legend

Purpose

These maps are the fact base for Phase 1. They redraw the 22 current-state maps produced for the Replacement Programme in a single consistent notation, and add what those maps do not show: control points, wait points, system versus manual steps, segment variants, and the five exception paths that were drawn as sub-process boxes without content.

Status of each map

Draft for validation: redrawn from the source with enrichment; to be confirmed in the named workshop. Straw-man: no source map exists; drawn from notes and RFP text to give the workshop something to correct. Nothing in a straw-man should be treated as fact.

Levels

L3 is the swimlane diagram: one per journey stage, actor lanes, decision points, hand-offs. L4 is the step table beneath it: one row per step with type, control, wait and observation. L4 detail that the source does not support is left blank rather than invented.

Identifiers

Map IDs: journey code + stage (NM-2 = New Money, Deal & Credit). Step IDs are unique within a map; lane prefix R = RM, S = system, K = Credit, C = customer, F = Fulfilment, G = Lending Services, Q = Securities, B = SBS, D = decision, X = sub-process, E = end. Control references Cn link to the control index on the next page and seed deliverable 1.6.

Observations

  • Steps S1–S4 and A1 (login → landing → search → located → retrieve) are identical in every journey mapped (H-B1).
  • The lending/deposit split is the only point where deposits touch the lending process; the deposit path has no workflow stages.
  • The initial overview (C0) is the only pre-credit filter and has no documented criteria; decline reasons at this point are not captured.
  • Lead receipt is unmanaged: there is no lead register or SLA from enquiry to first contact.

Open questions for WS-02

  • Is the CYB credit card enquiry form a live lead source? (source: TBC)
  • What share of enquiries are declined at initial overview, and is a reason recorded anywhere?
  • Can an RM legitimately create a deal without an opportunity today, and how often does this happen?

Observations

  • The facility letter is generated in BLP but issued manually by the RM as a PDF by email or post; the source states the preference for automation (H-C2, H-D3).
  • Three completion conditions (letter complete, pre-conditions met, security complete) converge before “ready for fulfilment”; there is no single view of which is outstanding.

  • How many deals hit the 3-month reset in the last 12 months?
