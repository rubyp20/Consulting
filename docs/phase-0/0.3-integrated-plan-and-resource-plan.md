## 3. Critical path

Data request (W1) → MI extract (W4–5) → cycle-time analysis (W4–6) → baseline (W7, G1) → routing criteria (W8–10) → control equivalence (W9–12) → Design Authority sign-off (W12) → G2 (W13).

Any slip in the MI extract moves G1 directly. Mitigation: activity survey and time-and-motion run independently and can carry G1 with a wider baseline range.
